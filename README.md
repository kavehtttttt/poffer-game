There is an initial screen where, if you don't have an account, you must first create one through the Sign Up option. After that, you can log in via the Login page.
There are also options for password recovery in case you forget your password.

Additionally, after logging in, you can edit your full name, email, password, username, and phone number.
You can also view the history of all your games and, of course, enter a game and start playing.
